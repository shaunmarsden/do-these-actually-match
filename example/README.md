# Worked Example

A fictional small hardware shop's stock count, done by hand, against its till system's export, both taken the same day. I built it to test five traps at once: a difference in units, a trivial formatting difference, a new delivery not yet logged, an incomplete count, and two real, unexplained conflicts in opposite directions.

- [physical-count.md](physical-count.md): the hand count as given
- [pos-system-export.md](pos-system-export.md): the till system's export as given
- [output.md](output.md): the reconciliation [SKILL.md](../SKILL.md) produces
- [review.md](review.md): whether it told each trap apart from a real disagreement
