## Genuinely Conflicting

- **Galvanised Hinges 75mm.** Physical count: 14. POS export: 22. Same unit on both sides, no presentation difference to resolve. A real gap of 8, direction: physical count is lower than the system.
- **Paint Brushes 2 inch.** Physical count: 30. POS export: 18. Same unit on both sides. A real gap of 12, direction: physical count is higher than the system.

## Only in One Record

- **Cordless Screwdriver Bit Set.** Only in the physical count (5 counted). The count notes state this delivery arrived the same morning and has not yet been entered into the till system. This is not a disagreement; the till system simply does not have this item yet.
- **Fence Post Caps.** Only in the POS export (8 recorded). The physical count notes state the fixings aisle shelf where these are kept was not reached during the count. This is not evidence the stock is missing; it is evidence the count is incomplete for this item.

## Presentation Differences Resolved, Not Reported as Mismatches

- **Wood Screws 40mm.** Physical count: 3 boxes of 200 (600 individual screws). POS export: 600, tracked per screw. Once converted to the same unit, both records show 600. This is not a disagreement.
- **Masonry Drill Bit 8mm.** Physical count: 12. POS export: 12.0. Same value, different decimal formatting. This is not a disagreement.

## Suggested Follow-Up for Human Approval

- Recount Galvanised Hinges 75mm and Paint Brushes 2 inch, since both show a real, unexplained gap in opposite directions and the evidence here does not say why.
- Log the Cordless Screwdriver Bit Set delivery into the till system.
- Complete the physical count for the fixings aisle shelf holding Fence Post Caps before treating that item as reconciled.

## What This Comparison Cannot Tell You

It cannot say why the two genuine conflicts exist, whether that is miscounting, an unlogged sale, a return, or something else, only that a real gap exists and in which direction. It also cannot confirm the actual stock level for Fence Post Caps, since only one record has a figure for it at all.
